# DevSentry

**AI-Powered DevOps Engineer for Cloud Troubleshooting & Incident Analysis**

AI-powered DevOps assistant for cloud troubleshooting and incident analysis.

DevSentry combines conversational AI, retrieval-augmented generation (RAG), controlled DevOps tools, incident analysis, application logs, and AWS infrastructure to help investigate common infrastructure and application problems.

---

## Overview

DevSentry is a conversational DevOps assistant designed to help engineers investigate infrastructure and application problems.
